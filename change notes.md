- Added a Rust workspace with a small Hello native add-on, SDK manifest and bounded protocol test host using the pinned Toolboks SDK, shared UI, protocol and catalog crates.
- Added Windows PR checks and per-add-on tag releases with main-ancestry/version validation, tests of the release executable, SHA-256 assets and executable size reporting. Expected tag-rejection tests finish with a successful CI exit code. Build credentials stay read-only.
- Added release-driven catalog PR automation using the host's format and compatibility metadata. Catalog publication requires owner review; a repository-scoped CATALOG_PR_TOKEN is required for bot PRs. The catalog now uses the owner's plain-list format: no signatures, keys, sequence numbers or validity dates. The empty catalog and tooling match host PR #134.
- Added Disk Manager as an independent `disk-manager.exe`, keeping its ID, five pages, scan/map/ranking behavior, preference keys and data location. It uses the pinned SDK runtime and shared styling. Suspending cancels scans and releases results while exports and analysis can finish in the background.
- Catalog generation now copies optional `host-services.json` page names and background behavior, preserving Disk Manager page links. Added `addon-repo measure <name>` for release executable size, first-frame timing and Windows idle memory. Add-on builds use the host's static CRT and System32 DLL-load restriction.
