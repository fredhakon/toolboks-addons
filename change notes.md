- Disk Manager: remembers completed scans locally in versioned, atomic binary files under its removable add-on data folder. Reopens the newest matching volume/root in the background, provides folder-time quick rescans with change counts and an always-available full rescan, preserves navigation and selection, and forces a full scan after exclusions change. Quick scans clearly state that in-place size changes can be missed. Remember my last scan and per-drive/all deletion controls manage saved file names; snapshots are limited to 384 MiB per root. The pinned host install-review access labels cannot describe large scan storage; privacy wording is included in add-on details and the page.

- Gaming profile: choices are grouped as Performance, Privacy and Cleanup. Each shows an evidence badge (Unproven, or Not a speed tweak for privacy and cleanup items), a one-line reason and its source. Nothing is selected by default, including Game Mode (it was before). Review changes is the main action and shows current and new values per choice; Apply stays disabled until you review the current selection, and says a restore point and registry backup do not guarantee full recovery.
- Disk Manager: Drive optimization shows drive health for the selected drive: a Healthy, Watch or Replace soon verdict with its reason, and a Details view with wear, available spare, temperature, media errors, unsafe shutdowns, power-on hours and reallocated, pending and unreadable sectors where the drive reports them. NVMe drives are read through the Windows storage query without administrator rights; SATA SMART data needs administrator rights in Windows, so those drives say so instead of showing values. USB, memory card, RAID and virtual drives that do not report health say that too. Thresholds are conservative and documented in the code; a missing value never raises the verdict.
